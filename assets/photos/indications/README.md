# Fotos de produtos indicados

Coloque aqui fotos reais dos produtos afiliados (preferencialmente WebP otimizado e com permissão de uso). Aponte o campo `image` em `indications-products.js` para o caminho relativo, por exemplo `assets/photos/indications/nome-do-produto.webp`.

Não use fotos dos produtos próprios da Cubic Maker para representar itens vendidos por lojas parceiras. Esta pasta começa sem imagens cadastradas para não exibir produtos fictícios.
